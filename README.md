# Теньки — макет сайта

Макет сайта базы отдыха «Теньки» на Волге. Короткая страница без долгой прокрутки, главное в ней — бронирование.

Один файл `index.html`, без сборки. Фото пока временные, непроверенные факты подчёркнуты пунктиром.

## Что на странице

1. **Первый экран.** Три слайда (домик, баня и чан, Волга) сменяются сами каждые 7 секунд. Новое фото въезжает шторкой справа, старое уезжает и темнеет, заголовок проявляется слева направо, на втором слайде справа выезжает белая колонка с карточками. Стрелки, пауза, свайп на телефоне. Внизу строка поиска: даты, гости, «Найти домик».
2. **Что забронировать.** Карточки домиков, бани, чана, беседки и рыбалки с ценами и фильтром. Фото въезжают шторкой, когда доходят до экрана. На телефоне карточки листаются лентой.
3. **Внутри домика.** Большое фото и светлая колонка с удобствами.
4. **Территория.** Фото, три миниатюры и кнопка «План территории» (план открывается в окне).
5. **Бронирование.** Форма с датами, гостями, домиком и допами (баня, чан, беседка), предварительный расчёт цены, список цен и правила. Пока модуль TravelLine не подключён, форма предлагает отправить заявку в WhatsApp с уже заполненными данными.

Высота страницы на компьютере около 5 экранов, на телефоне около 6,5. В старом варианте со скролл-видео было 20 и 22.

## Как посмотреть

Открыть `index.html` в браузере или запустить локальный сервер в папке:

```bash
npx http-server -p 8124
```

## Куда вставлять настоящие данные

- **Контакты, цены, время показа слайда** — объект `CONFIG` в начале скрипта. Цены там же используются для расчёта в форме.
- **TravelLine** — код модуля вставляется в `#tl-booking-form` в блоке бронирования. Как только модуль отрисуется, наша форма скроется сама.
- **Фото** — `assets/photos/`. Сейчас там кадры, вырезанные из референса заказчика в низком разрешении. Заменить настоящими снимками с теми же именами:

| Файл | Где на странице | Какой нужен кадр |
|---|---|---|
| `hero.jpg` | первый слайд, карточка «Домик у пирса» | домик среди елей, горизонтальный |
| `sauna.jpg` | второй слайд, карточка бани | парилка изнутри, тёплый свет |
| `volga.jpg` | третий слайд, карточка рыбалки | пирс на Волге на закате |
| `house.jpg` | карточка «Домик у елей», колонка второго слайда | второй домик снаружи |
| `chan.jpg`, `gazebo.jpg` | карточки чана и беседки | чан с паром, беседка с мангалом |
| `bedroom.jpg`, `kitchen.jpg`, `bathroom.jpg` | «Внутри домика» | спальня, кухня, санузел |
| `swing.jpg`, `play.jpg`, `grill.jpg` | «Территория» | общий вид, детская площадка, мангальная зона |
| `booking-bg.jpg` | фон бронирования | любой размытый кадр леса |
