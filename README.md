# Теньки — макет сайта

Макет сайта базы отдыха «Теньки» на Волге: тёмный, со скролл-видео «Один вечер в Теньках», переключателем «Лето / Зима» и местом под модуль бронирования TravelLine.

Один файл `index.html`, без сборки. Вместо кадров ролика пока нарисованные сцены, вместо фото — заглушки с подписью, какой нужен кадр. Непроверенные факты подчёркнуты пунктиром.

## Как посмотреть

Открыть `index.html` в браузере или запустить локальный сервер в папке:

```bash
npx http-server -p 8124
```

## Куда вставлять настоящие данные

Всё собрано в объекте `CONFIG` в начале скрипта: телефон, WhatsApp, Telegram, ролики для компьютера и телефона (`CONFIG.video`) и карта тактов подписей (`CONFIG.bands`). Код модуля TravelLine вставляется в `#tl-booking-form`.
